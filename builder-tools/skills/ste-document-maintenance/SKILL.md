# STE 文档写作与维护

以 ASD-STE100 Issue 9 的相关原则清楚表达，保留原意；中文和中英混用按语言自然表达。文档用途、读者及已有写入授权决定本次范围。

## 写作

- 保留事实、条件、数字、单位、因果关系、否定范围和确定程度。保留“可能、建议、计划、已完成、完成过”等承载的信息。
- 使用准确、常见的词和一致术语。专业名称、代码、命令、字段、链接和原始引用保持准确。
- 操作说明写清执行者、对象和动作；顺序动作分步，执行前必要的条件放在动作之前。
- 讨论和解释保留论据及取舍，按逻辑连接短句；一段集中说明一个主题。
- 指令直接表达需要完成的工作。细节、步骤和边界随当前任务需要增加。

需要核对具体英文规则或解释中文适配时，读取 [STE 规则参考](references/ste-issue9.md)。

## 维护

1. 阅读本次涉及内容及必要来源。维护长期记录时，核对其目标和当前决定。
2. 将实际变化更新并保存到目标记录，按对象和时间区分事实、判断、候选、决定及实际进度。同一条目或章节的确定程度统一标注一次（如状态列），仅在局部程度不同时单独说明，避免逐句重复保留语。
3. 当前入口保持总目标、当前决定、进度和下一步可见；详细依据及历史通过链接查阅。目标改变以用户明确决定为依据，旧决定保留变更原因及历史入口。
4. 保存后回读目标位置，核验请求的变更已写入，并对照来源检查信息完整性、状态和术语。重构时核对用户引文、关键条件及来源链接，并保留可恢复原稿；交接引用成果位置和下一步。

并发协作沿用项目的写入分工。需要结构参考时，按用途选择 [记录模块](assets/record-modules.md)。通常沿用既有结构；当前与历史混杂、入口过长时，在授权范围内调整组织方式。

交付正文或更新后的文件。说明与本次变化相称；需要解释的语义选择或证据缺口单独说明。
