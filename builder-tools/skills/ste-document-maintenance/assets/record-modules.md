# 轻量记录模块

根据文档用途选取需要的模块。通常沿用既有结构，结构妨碍接续时按用途调整。以下内容是项目记录参考，不是 STE 官方模板。短更新可以用一段话完成。

当前入口集中总目标、当前决定、实际进度、待定事项和下一步；详细研究及历史按需链接。文件较短时，这些内容可放在同一份文档中。

## 长期任务入口

```markdown
# 任务名称

总目标：希望最终获得什么结果，以及关键约束。
当前阶段：正在讨论、准备、执行或复核什么。

## 实施状态
说明目标事项的实际状态，例如“研究已完成；实施方案待确认”。

## 当前决定
已确认的方向及关键原因。

## 当前进度与下一步
实际进度、必要证据、下一步及责任者。

## 待定事项
仍需判断的问题、候选方案或关键证据缺口。

## 来源与成果
相关记录、原始来源和产出链接。
```

## 一项决定或变更

```markdown
日期：
变更内容与确认者：
依据或原因：
影响与后续动作：
```

## 任务交接

```markdown
目标与适用决定：
实际状态与证据：
成果位置及需要关注的问题：
下一步与责任者：
```

记录应区分已确认决定、建议及实际执行。字段按用途选择，相关成果和状态保留来源。
