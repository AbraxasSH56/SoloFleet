03 — Why this way

Built for one person, many bots.

A

One flat subscription

One Claude subscription runs every bot. Each reply shows a usage card.

B

Fewer, better questions

Unaddressed bots stay quiet; decisions come merged, with a recommendation.

C

Audited before done

No task closes without an independent, read-only audit.

Subscription use is Anthropic's call; see their help page (opens in a new tab).

More details
  • Every regular bot runs through the official claude command line (claude -p). No per-token meter per agent.
  • The usage card is on by default: model, pool, reasoning effort, files changed. The remaining-quota line needs the CodexBar command line (macOS) and two plugin options.
  • Included API credits, if your plan has them, run the scheduled audits and standby bots, and stop when they run out. No switch to paid usage.
  • Requests that wait on you sit on a ledger. It spares you remembering; it can't make you look.
  • A task card can't be marked done until an audit passed and the result hasn't changed since. What you say is written down that turn, so sessions reset daily.
  • No patches to OpenClaw: official settings, the plugin interface, one plugin.
04 — Safety

The desktop bot waits for you.

  • One bot on the screen, with a lock and queue.
  • Six actions need your click: paying, sending, deleting, submitting, uploading, installing. One click each.
  • No shell workaround: screen-driving commands are blocked.
  • Auditors are read-only.

Not a sandbox: some blocks match text, and button clicks aren't recognized yet. Safety doc (opens in a new tab)

More
  • Only the Desktop operator has screen tools. An exclusive lock and a queue mean one thread uses the screen at a time.
  • Only the owner's own Discord account clicking the approval card counts. Another bot can't approve. One approval releases one action.
  • If a card is denied, times out or is cancelled, that thread's screen tools can only look and close windows.
  • Shell commands that could drive the screen are blocked for the Desktop operator by matching command text, and its commands are sampled nightly.
  • A mouse click on a button relies on the bot's rule to stop first, backed by the lock and the card.
  • These are program-level guardrails and checkpoints. The safety doc lists what each one stops and what it doesn't.

06 — Before you try

Before you try.

  • An always-on Mac; desktop verified on macOS only.
  • OpenClaw, Node 24.16+, the claude CLI, a Discord bot per duty.
  • Some fixed protocol words are still Chinese.
  • Not yet built from scratch on a fresh machine.
  • You sign in yourself; the repo never touches your login.
  • One person uses it.
