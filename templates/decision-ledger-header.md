# Decision ledger

(The title and the labels below are the exact words the programs read.)

This ledger holds only the owner's decisions and the things decided NOT to be done. Decisions inside one project go in that project's `PROJECT.md`, not here.
Created: <YYYY-MM-DD>. Only the Controller writes; every bot reads.
Each entry has: title, date and scope, the owner's own words (if there are no verbatim words, write "Relayed, source: …"), and what it replaces. The [Authorization scope] block of a task card may say "based on D-xxx".
Always write models as aliases such as "latest Opus / Sonnet", never as version numbers; which version each alias means now is in the model table in your configuration.
An old approval does not turn into a standing permission by itself.
A quote marked "Transcribed" was copied from a decision record and was not checked against the original message.

Entry format (the programs check it: the title line is `### D-<three-digit number> <title>`, each entry needs a `Date:` line and a `Quote:` line, and numbers run without gaps):

```
### D-001 <title>
Date: YYYY-MM-DD; Scope: <which tasks or roles>
Quote: <the owner's words, verbatim; if none, Relayed, source: …>
Replaces: <None, or Replaces D-0xx>
```
