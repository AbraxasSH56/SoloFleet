# Master index

(The title and the table header below are the exact words the programs read: they find the project table by its first column "Project".)

This page is the single master index of where the current projects live. It does not copy task status, authorization or budget; those stay in the task board and in each project's own records. Read only the project entry you need for the current task, and do not treat this page as a task list.

One row per project. The Controller registers a row on the spot when a project is created, renamed or archived (create a project with the `new-project` command, which builds the project folder, the entry and this row in one go); the daily patrol checks the rows.

Write the channel column as `<channel name> (ID <digits>)` and the entry column as `[Project entry](projects/<project name>/PROJECT.md)`: the programs read the channel ID and the entry location from these two forms.
