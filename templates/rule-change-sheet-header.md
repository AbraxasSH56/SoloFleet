# 规则改法单

(Rule change sheet; the title and column names stay Chinese because the other rules refer to them by name.)

This sheet records "a new decision makes one sentence in one rule file out of date, and what it should be changed to". The Controller records the item, a development session makes the change, and the Controller reads it back. A rule change is a tier-C ("丙档") matter: it needs the owner's approval, and the approval and the registration live in the "等你定" ("waiting for you") ledger; **no task card is created**.

Status (状态) values: 待批 (waiting for approval) / 已批待改 (approved, to be changed) / 已改 (changed) / 不改 (will not change).
