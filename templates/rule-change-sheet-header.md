# Rule change sheet

(The title and the column names below are the exact words the other rules refer to.)

This sheet records "a new decision makes one sentence in one rule file out of date, and what it should be changed to". The Controller records the item, a development session makes the change, and the Controller reads it back. A rule change is a Tier C matter: it needs the owner's approval, and the approval and the registration live in the awaiting-decision ledger; **no task card is created**.

Status values: `pending` (waiting for approval) / `approved-to-change` (approved, to be changed) / `changed` (changed) / `not-changing` (will not change).
