# 换语言要改的地方

[English](../en/localization.md) | 简体中文

参考部署是用中文搭的，所以程序、规则文件和文件夹布局里有一些要按**中文字面**认的词。只翻译文档不够：这一页列出每一处按字面认的地方，让你自己决定怎么办。

## 现状

共用规则、角色头部、模板和定时任务指令都有英文和中文两版（`*.zh-CN.md`）。`locale`（默认 `en`，或 `zh-CN`）现在管三件事：

- **回复附卡上的文字**（型号行、修改行、额度行）和两句固定系统消息的替换句：`lexicon.mjs` 里中英两套都是完整的；
- **英文过程话清理**（回复是中文、开头夹英文"边想边说"的段落就删掉）：它是配合"一律说中文"的部署写的，所以只有 `locale` 是 `zh-CN` 时才开，`en` 时关；
- 审计守门拿哪个语言版的**任务指令片段**算指纹（`jobs/*.md` 或 `jobs/*.zh-CN.md`）。

`locale` 现在**还管不了**的是第 1 节列的那些字面词（进度句开头、卡片标签、报告首行、文件夹名）：`lexicon.mjs` 里有这些词的英文草稿，但**不管 `locale` 设什么，程序都还是直接认中文词**。所以：

- 这些中文字面词保持原样（英文规则里原样引出）；
- 想让 bot 用英文跟你说话，设 `replyLanguage`（默认 `English`）即可：英文规则会让 bot 用 `{{REPLY_LANGUAGE}}` 回话，并在程序要认的地方原样保留下面列的中文词（比如进度句仍以 `完成：` 开头）；
- 或者直接用中文规则和中文回话，什么都不用翻。

要做成完全英文的部署，得把下面列的词在代码、规则、模板、任务指令里**一起**改掉，再改测试。每一项都写了在哪个文件里认。

## 1. 程序按字面认的词

| 类别 | 字面词（zh-CN） | 在哪认 |
|---|---|---|
| 进度句开头 | `完成：` `进行中：` `没跑成：` `等主人：` `卡住：` | `scripts/automation/daily-format-check.mjs`（`STATUS_HEADS`）、规则 |
| 任务记录版式 | 状态行 `状态：`，小节 `当前状态`、`等主人拍板`、`当前成果`、`暂无（待写）` | `plugins/personal-inbox/project-files.mjs`、`daily-format-check.mjs`、`templates/任务记录.md`、`templates/项目入口.md` |
| 任务卡标签 | `【审计级别】`、`【授权范围】` 及其四行（`目标：` `允许做的：` `要主人确认的：` `停止条件：`），评论写法 `审计级别：A → B`；卡片自己的标签 `审计:`（半角冒号） | `daily-format-check.mjs`、`audit-gate.mjs` |
| 审计级别取值 | 卡片**标签**里 `审计:` 后面：`单审任务审计`、`单审独立`、`串联`；卡片**正文首行**（`【审计级别】…`）里：`单审（任务审计）`、`单审（独立审计）`、`串联` | `audit-gate.mjs`、`templates/任务记录.md`、规则 |
| 送审单和报告 | 首行 `任务审计 <@编号> 请审：…（第 N 次）`、`任务卡：`、`成果位置：`、`任务类型：`；报告首行 `我得：通过` ／ `我得：不通过（① N 项）` ／ `我得：审不了（这类内容审不了）`；审计线程标题前缀 `审计：` | `audit-gate.mjs`、`completion-notice.mjs`、规则 |
| 桌面求助 | `【求助】`、`【求助回复】` | `stuck-guard.mjs`、`desktop-lock.mjs` |
| 台账状态 | `收到` `已定` `撤销` `没回`，来源 `审批过期`，补登记前缀 `（程序补登记）`，`没截止` | `pending-ledger.mjs`、`pending-tools.mjs`、`request-watch.mjs` |
| 桌面排队跳过原因 | `不用了` `完成` `被接手`（`desktop-lock.mjs skip --why` 的取值） | `desktop-lock.mjs` |
| 额度接续 | 开头 `【额度恢复·程序代发】`，完成记录末尾的 `提醒：` | `quota-resume.mjs`、`completion-notice.mjs` |
| 决定账本 | `原话` 字样，待补清单里的字段名 | `ledger-watch.mjs`、`daily-format-check.mjs` |
| 发布摘要的任务名 | `巡查` `异常深审` `周审` | `scripts/automation/publish-self.py`、`plugins/personal-inbox/audit-guard-rules.json` |

**桌面敏感词**（`plugins/personal-inbox/sensitive-words.json`）不随 `locale` 走：中文词和英文词永远同时生效，因为这张表管的是付款、发送、删除和安装。想加你自己界面语言的词，就加在这里；换语言时最该先看的就是这一条。

有意不翻译的：`claude -p` 额度用完时的英文报错句（`quota-recovery.mjs` 按原句认）。

## 2. 文件夹和文件名

数据根里用的是中文名，程序按它们拼路径：

- 项目文件夹：`项目/<名>/{任务,成果,历史}`，入口 `PROJECT.md`，任务记录放 `任务/`；顶层有 `INDEX.md`、`决定账本.md`、`模板/`、`垃圾桶/`；
- 审计报告：`审计/{日审,周审,巡查,异常深审,异常标记,等你定,程序校验清单,发布/凭据}`；
- 运行记录：`运行记录/{结案,守门,卡线程,请示待核,账本待补,API额度,额度,看护,格式抽查,盲区抽查,文件对账,英文清理原文,提醒}`；
- JSON 状态文件用中文键名（比如账本待补清单里的 `日期`、`标题`、`原话`、`状态`）。

这些由程序和模板自己建，平时只会在数据根里见到。

## 3. 命令行参数名

已经是英文，不随 `locale` 变：见 [configuration.md](configuration.md) 第 6 节。

## 4. 时区和钟点

不是语言问题，但也是原部署里写死的另一处：所有日期都按 `config/crew.json` 的 `timezone` 算；脚本里的钟点见 [configuration.md](configuration.md) 第 5 节。

## 5. bot 怎么说话

人设是可选的（见 [roles.md](roles.md)）。规则文件只说"配了人设就照人设"，所以口头禅和人设说的语言属于人设，不属于规则。`replyLanguage` 只管回话的默认语言。

## 6. 建议的做法

1. 选好 bot 回话的语言（`replyLanguage`），中文字面词暂时原样保留。
2. 把你界面语言里的敏感按钮词加进 `sensitive-words.json`。
3. 如果状态词一定要换成你的语言，把第 1 节表里的词在代码、模板、规则、测试里**一起**改（搜中文词，每个词只出现在少数几个文件里），再把整套测试跑一遍。
4. 欢迎告诉我们（提 issue 或 PR）你改了哪些词；在 `lexicon.mjs` 里做出一套真正能用的 `en` 词表，是这个项目的下一步。
